# Orçamento de hospedagem — EcoCiclo

## Solução considerada
O README original informa que o site está publicado em `https://ecociclo-projeto.netlify.app`. A página de orçamento do projeto também compara serviços de hospedagem estática e registro de domínio.

## Estimativa registrada no material original
- Hospedagem estática gratuita: R$ 0,00 no plano gratuito, sujeita às condições e limites vigentes do provedor.
- Domínio `.com.br` via Registro.br: R$ 40,00 por ano, valor registrado na versão recebida do projeto.
- Total estimado com hospedagem gratuita e domínio próprio: R$ 40,00 por ano.
- Sem domínio próprio, usando o subdomínio fornecido pelo serviço de hospedagem: R$ 0,00.

## Justificativa
Para um site acadêmico estático feito com HTML, CSS e JavaScript no navegador, uma plataforma de hospedagem estática é suficiente para publicar os arquivos sem manter servidor próprio. O HTTPS deve estar ativo na publicação.

## Observação de atualização
Os valores acima são os que constavam no material original do projeto; não são uma cotação em tempo real. Antes de apresentar como preço atual, confirmar no site oficial do provedor e do Registro.br. A escolha final deve refletir o serviço realmente utilizado no deploy.
